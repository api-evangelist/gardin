# Gardin

> Gardin is a UK agritech company whose product, Gardin Pulse, is a real-time plant-level crop intelligence platform built on an optical sensor that measures chlorophyll fluorescence to assess photosynthetic efficiency. The Gardin API exposes sensor/device management, an asynchronous bulk Query API for chlorophyll-fluorescence and Gardin-indices data, and a Notification API delivering plant-health alerts over webhooks and websockets. Authentication is OAuth2 client-credentials (Bearer JWT).

## APIs

- [Gardin API reference](https://developers.gardin.ag/docs/gardin-api/gardin-api): Full HTTP API reference (Query, Sensor Management, Notification).
- [Query API - submit a query](https://developers.gardin.ag/docs/gardin-api/submit-a-new-query): POST /query for ChF/indices data (async submit-poll-download).
- [Sensor Management - list sensors](https://developers.gardin.ag/docs/gardin-api/list-all-sensors): GET /devices with limit/skip paging.
- [Notification API - plant alert](https://developers.gardin.ag/docs/gardin-api/plant-alert): Webhook/websocket plant-health alerts, HMAC-SHA256 signed.
